## Sobre el proyecto

**Task Manager** es un proyecto personal creado para practicar el desarrollo de una aplicación Java desde cero, empezando por una versión por consola y evolucionándola hasta una interfaz gráfica con Swing.

El objetivo principal del proyecto no es crear una aplicación compleja, sino trabajar de forma ordenada conceptos fundamentales como la **Programación Orientada a Objetos**, la **separación de responsabilidades**, el uso de **Git/GitHub** y la creación de una interfaz gráfica funcional.

Durante el desarrollo se ha seguido un flujo progresivo, realizando commits por cada avance importante y separando la lógica del programa de la parte visual.

## Funcionalidades principales

<table>
  <tr>
    <td width="50%">
      <h3>Añadir tareas</h3>
      <p>Permite crear nuevas tareas desde la interfaz gráfica mediante un campo de texto y un botón de acción.</p>
    </td>
    <td width="50%">
      <h3>Validación de entrada</h3>
      <p>Evita que el usuario pueda añadir tareas vacías o formadas únicamente por espacios.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>Listado visual</h3>
      <p>Las tareas se muestran en una lista integrada dentro de la ventana principal de la aplicación.</p>
    </td>
    <td width="50%">
      <h3>Estados de tarea</h3>
      <p>Cada tarea puede mostrarse como <code>Pendiente</code> o <code>Completada</code>.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>Marcar como completada</h3>
      <p>El usuario puede seleccionar una tarea de la lista y actualizar su estado desde la interfaz.</p>
    </td>
    <td width="50%">
      <h3>Contador de progreso</h3>
      <p>La aplicación muestra el número total de tareas y cuántas han sido completadas.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>Avisos integrados</h3>
      <p>Los mensajes de error o confirmación aparecen dentro de la propia interfaz, sin ventanas emergentes molestas.</p>
    </td>
    <td width="50%">
      <h3>Versión por consola</h3>
      <p>El proyecto conserva una primera versión por terminal, usada para construir la lógica antes de pasar a Swing.</p>
    </td>
  </tr>
</table>
